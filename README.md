# LSIP — ปุ่มปิดงวดและคำนวณงวดถัดไป

ที่เก็บนี้มีเฉพาะปุ่มเริ่มงานแบบใช้ครั้งเดียว ไม่มีสูตร ไม่มีฐานข้อมูล และไม่มีผลพยากรณ์

## ทุกงวดทำเพียง

1. ตรวจผลกองสลากว่าประกาศครบแล้ว
2. เปิด GitHub
3. เปิด `lsip-zero-cost-trigger`
4. กด `Actions`
5. เลือก `LSIP — ปิดงวดและคำนวณงวดถัดไป`
6. กด `Run workflow`
7. พิมพ์ `YES`
8. กด Run
9. รอเครื่องหมายเขียว
10. กดลิงก์ `ดูผลฉบับเต็มใน LSIP ส่วนตัว`

ใช้ได้จากเว็บ GitHub บนมือถือ งานจะทำต่อแม้ปิดหน้าเว็บ หลังจบแล้วเครื่องชั่วคราวจะปิดเอง ไม่มี Server ไม่มีการเฝ้าดูผลอัตโนมัติ และไม่มีค่าบริการโครงสร้างพื้นฐานประจำ

ถ้างานขึ้นสีแดง ให้เปิดดูเฉพาะสถานะที่แสดงไว้และอย่ากรอกเลขรางวัลด้วยตนเอง ข้อมูลฉบับเต็มเก็บอยู่ใน LSIP ส่วนตัวเท่านั้น
